# Licenses

Daylight is original work. It does not include f.lux source, branding, or assets.

This package has **no third-party Swift dependencies**. It uses only Apple system frameworks:

- Swift / AppKit
- Core Graphics
- ColorSync
- IOKit
- ServiceManagement
- Foundation

DisplayServices is an optional experimental runtime lookup for built-in brightness. It is not linked as a required private framework.
